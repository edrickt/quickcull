# docs

Living documentation for QuickCull. The user-facing manual is the repo-root
`README.md`; the contributor guide is `AGENTS.md`.

- `assets/` holds images referenced during design (icon options).
- `audits/` holds the current code-quality audit reports, newest last.
- `archive/` holds executed history: per-feature plans and design specs, past
  code-audit reports, and the superseded wave-3 audit brief. Kept for
  reference; nothing here describes current work.
