# Grid View Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a toggle grid view of all session images — adaptive LazyVGrid reusing the thumbnail cache — with single/Cmd/Shift multi-select, `Z` to batch-flag, and double-click to jump to scrub at that photo; filter `All/Flagged/Keepers` applies to both views.

**Architecture:** `Session` gains `toggleFlags(ids:Set<String>)->Bool` batch method (single projection recompute). `ImageWindow` gains `ensureLoaded(indices:)` to lazily load arbitrary grid-visible thumbs beyond the ±30 scrub window. `AppState` owns `viewMode` (`.scrub`/`.grid`) and `gridSelection: Set<String>` (id-based, stable across filters) and branches `Z` between single and batch. `GridView` is a new SwiftUI view; `ScrubView` becomes a container toggling scrub vs grid with a shared toolbar (view toggle + existing filter + trash).

**Tech Stack:** Swift 6, SwiftUI, Observation (`@Observable`, `@Environment`), XCTest (macOS, `xcodebuild` + `xcrun xctest`), `CGImage`/`ImageIO` thumbnails via `ImageCacheStore`.

## Global Constraints

- Requires Xcode 16+ on macOS 14+ (README Build).
- Decode pipeline unchanged: LibRaw 0.22.1 dynamically linked (LGPL-2.1), `DecodeEngine`→`ImageCacheStore`→`ImageWindow`; grid reuses the 320px thumbnail cache (no new decode path).
- Default `viewMode` is `.scrub`; `gridSelection` resets on new import; `viewMode` resets to `.scrub` on new import.
- Filter is per-session (`Session.filter` projection over `allFiles` → `files`); grid iterates the same `session.files` as filmstrip, so filter applies to both views identically.
- Empty `session.files` (e.g. Flagged with 0 flags) shows empty placeholder, does NOT fall back to All in this grid spec (commit/filter toggle still has existing fallback logic; batch flag has its own empty→All fallback per spec).
- Toolbar only — no new keyboard shortcut for view toggle in v1; `Z` is the only flag key (existing `CullKeyMap`/`KeyboardMonitor`).
- Grid does NOT show filenames in v1, only image + `FlagBadge` (size 24) + selection stroke.
- `ImageWindow` memory bounded: viewport thumbs (~20–40) + scrub window 61; `ensureLoaded` must not break that invariant.
- Harness build workaround: every `xcodebuild` invocation needs `export TMPDIR=/tmp/qc-tmp CLANG_MODULE_CACHE_PATH=/tmp/qc-modcache` and `OTHER_SWIFT_FLAGS="-Xfrontend -disable-sandbox"` (see Build / Test Commands).
- Naming: `ViewMode` enum in `AppState` namespace, `gridSelection: Set<String>` (ids), `toggleFlags(ids:)`, `ensureLoaded(indices:)`, `GridView` file `QuickCull/GridView.swift` (Xcode synchronized groups — no `.pbxproj` edit).

- [ ] **Step 3: Implement `toggleFlags(ids:)`** — in `QuickCullCore/Session/Session.swift` after `toggleFlag() -> Bool`, insert:

```swift
    /// Batch-toggles flags for the given ids (intersection with `allFiles`).
    /// Recomputes the projection once. If the current photo is still visible
    /// it stays current; otherwise the nearest match in full-list order takes
    /// over (ties forward). An empty projection falls back to `.all` keeping
    /// the previous current photo by id. Returns whether the projection
    /// size changed or the filter fell back.
    @discardableResult
    public func toggleFlags(ids: Set<String>) -> Bool {
        guard !allFiles.isEmpty, !ids.isEmpty else { return false }
        let validIDs = ids.intersection(allFiles.map(\.id))
        guard !validIDs.isEmpty else { return false }
        let beforeCount = files.count
        let beforeFilter = filter
        let currentIDBefore = files.isEmpty ? nil : currentFile.id
        for id in validIDs {
            if flagged.contains(id) { flagged.remove(id) } else { flagged.insert(id) }
        }
        let newFiles = projection(for: filter)
        if newFiles.isEmpty {
            filter = .all
            files = allFiles
            if let cid = currentIDBefore, let idx = allFiles.firstIndex(where: { $0.id == cid }) {
                currentIndex = idx
            } else {
                currentIndex = 0
            }
            return true
        }
        files = newFiles
        if let cid = currentIDBefore, let idx = newFiles.firstIndex(where: { $0.id == cid }) {
            currentIndex = idx
        } else if let cid = currentIDBefore {
            currentIndex = nearestMatchIndex(to: cid, in: newFiles)
        } else {
            currentIndex = 0
        }
        return files.count != beforeCount || filter != beforeFilter
    }
```

Note: If `files` is already empty (empty filter), `currentIDBefore` is nil; batch still flips flags and falls back as above. The `allFiles.isEmpty` guard mirrors `setFilter`.

```swift
    private var ensuredIndices: Set<Int> = []

    public func ensureLoaded(indices: [Int]) {
        let policy = WindowPolicy(radius: radius)
        let windowSet = policy.window(around: currentIndex, count: count)
        for idx in indices where idx >= 0 && idx < count {
            ensuredIndices.insert(idx)
        }
        // Evict anything outside window ∪ ensured
        let keep = windowSet.union(ensuredIndices)
        for i in Set(images.keys) where !keep.contains(i) {
            images.removeValue(forKey: i)
            inFlight.remove(i)
        }
        // Load ensured indices not yet present (plus window, which setCurrent already queued but ensure we cover moved current)
        let toLoad = (windowSet.union(ensuredIndices)).filter { images[$0] == nil && !inFlight.contains($0) }
        // But actually only queue the explicitly ensured indices; window already queued by setCurrent. So filter to ensured:
        for i in ensuredIndices where images[i] == nil && !inFlight.contains(i) {
            inFlight.insert(i)
            Task { [weak self] in
                let image = await loader(i)
                guard let self else { return }
                self.inFlight.remove(i)
                // Still keep if current moved but still in ensured/window
                let currentKeep = WindowPolicy(radius: self.radius).window(around: self.currentIndex, count: self.count).union(self.ensuredIndices)
                guard currentKeep.contains(i) else { return }
                if let image { self.images[i] = image }
            }
        }
        // Also prune ensuredIndices that are now out of window and not recently re-ensured? Keep for simplicity; eviction already handles images.
        // But to avoid unbounded ensuredIndices growth, intersect with count range:
        ensuredIndices = ensuredIndices.filter { $0 >= 0 && $0 < count }
    }
```

```swift
    public func setViewMode(_ mode: ViewMode) {

    public func selectSingle(id: String) {

    public func selectRange(to targetID: String) {
        guard let anchor = gridAnchorID,
              let session,
              let anchorIdx = session.files.firstIndex(where: { $0.id == anchor }),
              let targetIdx = session.files.firstIndex(where: { $0.id == targetID }) else {
```
